## Detailed Vulnerability Breakdown

### [SEC-FIND-001] Missing Authorization / IDOR on Patient Deletion
- **Severity:** High
- **File:** [EndoViewModel.kt](file:///c:/Users/hemas/OneDrive/Desktop/endo%20app%20final/endo_app/endo%20app/app/src/main/java/com/simats/endo/EndoViewModel.kt)
- **Location:** `deletePatient (line 368-372)`
- **Evidence:** `SupabaseClient.client.postgrest['reports'].delete { filter { eq('id', id) } }`
- **Impact:** Any authenticated doctor can delete reports generated by any other doctor if they know the report UUID.
- **Recommendation:** Enforce RLS (Row Level Security) on Supabase, and check both auth.uid() and patient ownership in the delete clause.
- **Status:** Open

### [SEC-FIND-002] Hardcoded Sensitive Secrets in Local Configuration
- **Severity:** Medium
- **File:** [local.properties](file:///c:/Users/hemas/OneDrive/Desktop/endo%20app%20final/endo_app/endo%20app/app/src/main/java/com/simats/endo/local.properties)
- **Location:** `Lines 9 & 12`
- **Evidence:** `GEMINI_API_KEY=AQ.Ab8... / SUPABASE_ANON_KEY=eyJhb...`
- **Impact:** Leaking secrets in local files can lead to repository leaks or local compromise.
- **Recommendation:** Store API keys in system environment variables or secure keystore vaults, loading them dynamically.
- **Status:** Open

---

### [SEC-FIND-003] Missing Input Validation on Patient Fields
- **Severity:** Medium
- **File:** [EndoViewModel.kt](file:///c:/Users/hemas/OneDrive/Desktop/endo%20app%20final/endo_app/endo%20app/app/src/main/java/com/simats/endo/EndoViewModel.kt)
- **Location:** `saveReportToDatabaseAndLocal (line 388-403)`
- **Evidence:** `insertedPatient = SupabaseClient.client.postgrest['patients'].insert(newPatientDb)`
- **Impact:** Malicious HTML injections or SQL payload data could pollute the tables or corrupt displays.
- **Recommendation:** Add regex and length constraints for age, full_name, and primary_diagnosis before DB operations.
- **Status:** Open

---

### [SEC-FIND-004] No SSL Certificate Pinning
- **Severity:** Low
- **File:** [AndroidManifest.xml](file:///c:/Users/hemas/OneDrive/Desktop/endo%20app%20final/endo_app/endo%20app/app/src/main/java/com/simats/endo/AndroidManifest.xml)
- **Location:** `Application configuration`
- **Evidence:** `Missing <network-security-config> tag.`
- **Impact:** MitM attacks could intercept data transiting to Supabase.
- **Recommendation:** Define an XML network security config enforcing SSL pinning on the Supabase domains.
- **Status:** Open

---

### [SEC-FIND-005] Weak Password Policy
- **Severity:** Low
- **File:** [EndoViewModel.kt](file:///c:/Users/hemas/OneDrive/Desktop/endo%20app%20final/endo_app/endo%20app/app/src/main/java/com/simats/endo/EndoViewModel.kt)
- **Location:** `signUpWithEmail (line 211-225)`
- **Evidence:** `Accepts raw email/password without complexity validation.`
- **Impact:** Weak user accounts are susceptible to brute-force takeovers.
- **Recommendation:** Validate length, digits, and special character presence on the client-side before calling Supabase auth API.
- **Status:** Open
